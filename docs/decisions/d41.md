## D41

[v5 失敗](../gates/gate-12a-observed-smoke-v5.md)保存 24 份真 frame：兩個 instance
分別顯示 `fix typecheck errors` 與 `fix lint errors`；只替換建議文字，其他 tokens
即符合既有 Ready fixture。原完整 literal 辨識均回 None，180 秒初始 idle 逾時，零工作訊息。
全新 verifier 編譯當時的實際 Rust classifier 重現此差異。
使用者先詢問文字是否變化，再明確確認「視為可變」，採用只放寬建議欄位的方案。

| 範圍 | 規則 |
|---|---|
| 可變 | 唯一 `❯ Try "…"` 建議引號內文字；完整單行、非空、長度受欄寬限制 |
| 拒絕 | 缺引號、額外引號／token、重複建議、換行／控制字元、超出欄寬、位置改變 |
| 仍固定 | Claude 2.1.284、100／140×24、canonical workspace 與完整 header／channel／footer 的其餘 tokens |
| 選單 | TrustNo／TrustYes／Development 仍完整 literal；三鍵 intent／written、generation／revision 與控制權規則不變 |
| 初始 idle | 仍要 fresh live SessionStart、同 generation、已知 Ready 穩定五秒及投遞前重新核對；Ready 不新增按鍵 |

這是對 [D40 P5／P6](d40.md) 的局部補充，沒有新增 transport、ACK 或自動重送。
「Ready 建議文字可變」不等於未知選單可接受，也不把 UI header 當 assistant resolved model 證據。
沿用既有非建議區 whitespace token 比對，canonical path 仍另行精確核對。
