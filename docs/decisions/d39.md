## D39

- 決定：採用 [C 段 P1–P6](../gates/gate-11c-proposal.md)；下表摘要不取代提案的協定、時序與限制。

| 項目 | 決定 |
|---|---|
| P1 | `t` 唯讀、`i` 完整模式；尺寸／frame 確認後輸入，只留底部一列；Ctrl-] 返回，斷線重連再按 i |
| P2 | holder alacritty 提供 frame／歷史，TUI 只經 client／daemon；client 1.4／holder 1.1 加法能力，一般 NEEDED 保留 1.3；不足則純文字唯讀 |
| P3 | 最後按 i 的連線取得 resize／input 控制，其他視窗唯讀；舊操作完成或作廢後才交接，釋放不自動還權；有控制者時拒絕無 attach 的 legacy input |
| P4 | 依 holder mode 編碼按鍵／mouse／paste；Shift 滾輪本機歷史，normal screen 1,000 列；超限 paste 整次拒絕 |
| P5 | fake Codex 整合與 opt-in 真 Codex smoke 驗完整 AgEnD U17，記錄版本，通過且使用者確認後才開已驗版本；未驗保留 not_supported |
| P6 | core → holder → runtime／daemon／client → TUI → Codex 整合；自動驗證、雙平台 CI、fresh verifier、逐步人工驗收與另行 merge 確認 |

- 理由：holder 是唯一終端狀態來源；輸入與尺寸共用控制者，避免多視窗互相干擾；Codex 不以局部 spike 代替完整整合證據。
- 否決的方案：t 直接輸入、TUI 第二個 parser、多視窗同時輸入、滾輪一律轉上下鍵、未驗便開所有 Codex 版本。
- 證據：[逐項確認紀錄](../gates/gate-11c-proposal.md#使用者確認紀錄)，2026-10-02；提案 [PR #144](https://github.com/suzuke/AgEnD/pull/144)。使用者另指示「#144合併」，不包含實作 PR 的合併授權。

C 段 P3／P5 是後來確認的設計，實作完成後取代原 C 段僅「最後開啟尺寸為準」及 B 段 Codex 一律拒絕的範圍；B 段歷史保持原文。Codex 的 P5 驗證門檻通過前，現行拒絕仍有效。
